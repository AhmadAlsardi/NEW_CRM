Smart Media CRM Training Simulation

Open index.html in Chrome/Edge.
This is a local training simulation. It does not submit credentials or data to the real CRM.

Main flow:
Login -> Dashboard -> Projects -> Smart Media Training Project -> Design Training Task
or Tasks -> Design Training Task

Timer, comments, and timesheets are saved locally in the browser using localStorage.
Use “Reset Training Data” in the Arabic guide to clear the training entries.

Important Links use the images supplied in the conversation.

Version 2 refinements: horizontal table scrolling, interactive dashboard tabs, functional calendar views/navigation, time/date popover, project date filtering, improved Tasks Overview, and cleaner Arabic guide formatting.
